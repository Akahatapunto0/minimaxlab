Qué creaste

Creé la estructura completa de un pequeño juego estratégico entre un ratón y un gato usando Python, aplicando el algoritmo Minimax, funciones de distancia, evaluación heurística, movimientos válidos y toda la lógica necesaria para que el ratón tome decisiones inteligentes dentro del tablero.

Qué funcionó

Lo que realmente funcionó fue usar ChatGPT para capitalizar y armar una visión general del proyecto.
De otra manera, yo no hubiera sabido por dónde iniciar ni cómo encajar todas las piezas. ChatGPT me ayudó a ver el proyecto desde arriba, a entender qué hace cada parte y cómo se relaciona con las demás, y así pude organizar todo el código y la lógica del juego.xiste la heurística, por qué se usa profundidad, por qué el return tiene dos valores y qué significa cada número. En ese momento el código dejó de ser magia y pasó a ser algo que realmente entendí.

Qué fue un desastre

Lo que fue un desastre es que tenía funciones sueltas sin entender cómo se conectaban. Es que todavía me cuesta entender la lógica para generar un mapa completo en Python. Necesito más tiempo de aprendizaje para poder usar el código de forma libre y natural.

Mi mejor “¡ajá!”

Mi mejor ajá fue entender cómo funciona todo por bloques y que ninguna función está al azar. Me di cuenta de que el 90% del código son comandos pensados para simplificar la ejecución.
